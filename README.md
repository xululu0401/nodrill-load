# 免打孔承载装置对账台（nodrill-load）

不能打孔的时候（租房、宿舍、瓷砖墙、办公室），东西只能靠**背胶、真空吸盘、撑杆、磁铁**固定。
麻烦在于三件事只能靠猜：这样装**到底能挂多重**、**几年后还够不够**、**要挂住目标重量该改什么**。

本页把每种安装方式的**多项约束同时摆开、取最小的那一项**，算出实际安全系数与逐年衰减，指出瓶颈是哪一项，
并反推「需要多大粘贴面积 / 多大的吸盘 / 多粗的杆 —— 还是根本做不到、只能打孔」。

## 四种安装方式的模型

| 方式 | 能力公式 | 说明 |
|---|---|---|
| 背胶 / 免钉胶 | `F0 = σ_eff × 100 × area × keep/100` | 顺墙（剪切）用剪切强度，往外拉（剥离）用剥离强度，两者常常差一个量级 |
| 真空吸盘 | `F0 = dP × 0.1 × (π·cupD²/4) × keep/100 × cups` | 顺墙方向还要再乘侧向滑移系数（滑移通常才是封顶项） |
| 撑杆 / 顶天立地 | `N_eff = min(弹簧, 欧拉屈曲, 管材屈服, 墙面压强)`；`F_fric = 2μN_eff`；`F_bend = 4σ·100·W/L`；`F0 = min(F_fric, F_bend)` | 瓶颈常常是「管子自己会弯」而不是摩擦 |
| 磁吸 | `F0 = magQ × magA × keep/100 × tempK/100` | 单位面积吸力由用户按磁铁规格自填 |

- 年衰减（四种方式统一）：`F(t) = F0 × (1 − decay/100)^t`，把胶体蠕变、吸盘泄漏、橡胶老化、弹簧松弛合并成一个年衰减率
- 判定：`ratio(t) = F(t) / (目标载荷 × 动载系数)`；`ratio(T) ≥ SF` → 够；`1 ≤ ratio(T) < SF` → 没余量；`< 1` → 会掉
- 反推：`F0_req = 有效载荷 × SF / (1 − decay/100)^T`，按方式解出所需参数，**一律向上取整并回代重算**，超上限时如实判「做不到」

单位：1 MPa = 100 N/cm²、1 kPa = 0.1 N/cm²、1 kgf = 9.80665 N。

## 结构与命令

```
01-nodrill-load/
  index.html          单文件成品（core.js + ui.js 内联，直接双击可开）
  core.js             计算引擎（AppCore）：校验 / 四种方式约束 / 逐年衰减 / 反推 / 15 项结构自检 / 导出文本
  ui.js               界面与导出（CSV / MD / JSON / 1080×1350 结果卡 PNG）
  template.html       页面骨架与样式（build.cjs 的输入）
  build.cjs           把 core.js、ui.js 内联进 template.html 生成 index.html
  tests/core.test.cjs node --test 的核心测试（39 项）
  cover.png           封面 1200×1200
```

```bash
node build.cjs                 # 生成 index.html
node --test tests/core.test.cjs  # 核心测试
python3 make-cover.py          # 封面（需 Pillow）
```

上层目录另有 `需求与调研.md`（调研留证 + 需求简报）、`说明.txt`（发布用全文）、`发布物料.json`、
`status.json`、`质检报告.md`、`evidence/`（锚点、核心测试输出、浏览器验收结果、截图、下载文件、部署与发布回执）。

## 边界（完整清单见页面「这份账不算什么」）

- 不做任何产品合格判定，不引用也不替代任何标准（GB / EN / ISO 等）的条款、检测方法或工程验收，不针对任何真实品牌、产品、事件或当事人。
- 静力线性模型：不做疲劳、冲击谱、蠕变曲线、温度循环、紫外老化；年衰减率是用户自填的合并假设，不是材料实验数据。
- 背胶不建模偏心力矩、剥离前沿扩展与基材差异；吸盘不建模曲面、抽气方式与泄漏面积；撑杆只做「两端铰接、载荷作用于管中点」的简支模型与欧拉屈曲；磁吸不建模磁路、气隙与温度退磁曲线。
- 不联网、不查任何产品参数、不做购买建议；判定三档只是本页内部的显示分组，不是任何标准的安全等级。
- 默认样例与 9 个内置场景全部是虚构示例；其中「门框单杠（假设有人拉）」只用于演示动态载荷口径，不对任何真实产品、事件或人作判断。
